# Motor Vehicle Inspection Form

A professional digital inspection form for capturing detailed motor vehicle condition reports.

## Features

- 6-section inspection workflow with validation
- Condition ratings (Excellent, Good, Fair, Poor, N/A)
- Photo uploads with drag-and-drop
- Auto-generated inspection report
- PDF export and print support
- GibeonTech branded letterhead

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Deploy on Vercel

This project uses **Next.js**. Connect the repository to Vercel — it will detect Next.js automatically. Ensure the **Root Directory** points to the folder containing this `package.json`.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- React Hook Form + Zod
- jsPDF + autoTable
